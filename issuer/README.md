# zk-MatchID: Trusted Issuer Service

Simulates institutional identity providers (Government, Universities, Employers) that issue digitally signed Verifiable Credentials (VCs).

## Features
- Generates standard W3C-compliant Verifiable Credentials.
- Signs credentials with issuer private keys.
- Prepares sample credentials for local vault testing.

## Usage

```bash
cd issuer
npm run issue
```
